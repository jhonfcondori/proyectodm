# SRD attribution

No SRD data is bundled in this repository yet. It will be added in Phase 4.

When SRD content is included, this file must document the exact source and license:

- **SRD 5.1 (2014)**: licensed under the Open Gaming License v1.0a. Include the full OGL text and Section 15 copyright notice.
- **SRD 5.2 (2024)**: licensed under Creative Commons Attribution 4.0 International (CC BY 4.0). Include the required attribution and a link to the license.

Only content released under those licenses may be committed to the public repository. Homebrew or proprietary content must stay in the user's local vault.
